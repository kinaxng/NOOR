## 前置要求

### 1. NVIDIA Driver + Container Toolkit

```bash
# 验证宿主机 GPU 可访问
nvidia-smi
# 应显示 Driver Version, CUDA Version, GPU 型号

# 验证 nvidia-container-toolkit
docker run --rm --gpus all nvidia/cuda:12.8.0-runtime-ubuntu22.04 nvidia-smi
```

**Driver 版本对照**：
| Driver | 支持 CUDA | 适配容器 CUDA |
|--------|---------|-------------|
| 560.x | ≤ 12.6 | 12.8 ✓ |
| 575.x | ≤ 12.4 | 12.8 ✓ |
| 590.x | ≤ 13.1 | 12.8 ✓ |

### 2. Docker 环境

- Docker Engine 20.10+
- docker-compose v2 (或 `docker compose` plugin)
- NVIDIA Container Toolkit

安装 NVIDIA Container Toolkit（Ubuntu）:
```bash
distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
curl -fsSL https://nvidia.github.io/nvidia-docker/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-docker.gpg
curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | \
    sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-docker.gpg] https#g' | \
    sudo tee /etc/apt/sources.list.d/nvidia-docker.list
sudo apt-get update && sudo apt-get install -y nvidia-container-toolkit
sudo systemctl restart docker
```

## 构建与启动

### 1. 准备宿主机模型目录

**方案 A：使用现有模型（推荐，已有本地环境）**

```bash
# 如果你已有本地模型（/volume1/models/），直接创建软链接：
mkdir -p ~/noor
ln -s /volume1/models ./models
```

**方案 B：首次部署，需要下载模型**

```bash
mkdir -p models/lada_model_weights models/huggingface

# lada 模型：按 lada-cli 文档放到 models/lada_model_weights/
# Whisper 模型：首次运行时会自动下载到 HF_HOME 目录
```

### 2. 配置环境变量

```bash
cp .env.docker.example .env.docker
nano .env.docker  # 按需修改
```

`docker-compose.yml` 已通过 `env_file: .env.docker` 注入后端容器环境，不需要再把 `.env.docker` 手动挂载成 `/app/.env`。

关键配置项：

```bash
# 模型目录（容器内路径，映射自宿主机 ./models）
LADA_MODEL_WEIGHTS_DIR=/app/models/lada_model_weights
HF_HOME=/app/models/huggingface

# LADA CLI（pip 安装后位于 PATH 中）
LADA_CLI_PATH=lada-cli

> 升级说明：Docker 模式下建议通过更新镜像并重建容器来升级 LADA，
> 不建议在运行中的容器内直接执行 git pull / pip install。

# 视频文件（宿主机目录映射到容器内 /Videos）
SOURCE_DIR=/Videos
OUTPUT_DIR=/Videos

# Emby（如使用）
EMBY_SERVER=http://your-emby-server:8096
EMBY_API_KEY=your_api_key
```

### 3. 构建镜像

```bash
# 拉取 CUDA 基础镜像（首次约 2-3GB）
docker compose pull

# 构建（首次约 10-20 分钟，取决于网络）
docker compose build --no-cache
```

### 4. 启动

```bash
docker compose up -d
docker compose logs -f   # 查看日志
```

访问：
- 前端: http://localhost (Nginx :80)
- 后端 API: http://localhost:9898
- 后端直接访问（调试）: http://localhost:9898

### 5. 验证 GPU 可用性

```bash
# 进入后端容器
docker compose exec backend bash

# 验证 torch 可以看到 GPU
python3 -c "import torch; print(f'CUDA: {torch.cuda.is_available()}, Device: {torch.cuda.get_device_name(0)}')"

# 验证 lada-cli 可用
lada-cli --help

# 验证 ffmpeg 可用
ffmpeg -version | head -1
```

## 宿主机模型准备

### LADA 模型

将已有的 `lada_model_weights` 目录复制到 `./models/lada_model_weights/`：

```bash
# 宿主机上
cp -r /volume1/models/lada_model_weights ./models/
```

或创建软链接（节省磁盘空间）：

```bash
ln -s /volume1/models/lada_model_weights ./models/lada_model_weights
```

### Whisper 模型

Whisper 模型会在首次运行时自动下载到 `$HF_HOME`（`/app/models/huggingface/`）。

也可以手动预下载：

```bash
docker compose exec backend bash
python3 -c "
from huggingface_hub import snapshot_download
snapshot_download(repo_id='guillaumekln/faster-whisper-large-v3', cache_dir='/app/models/huggingface')
"
```
