# Troubleshooting

## 前端无法连接后端

1. 确认后端监听 `127.0.0.1:9898` 或配置的地址。
2. 检查前端代理、反向代理和 CORS 设置。
3. 查看浏览器 Network 面板中的失败请求。
4. 检查后端日志，不要在公开 Issue 中直接粘贴未脱敏日志。

## 插件商店为空

确认仓库列表包含：

```text
https://github.com/kinaxng/NOOR-Plugins
```

然后检查服务器是否能访问 GitHub 与 `raw.githubusercontent.com`。代理或 GitHub 镜像配置错误也会导致索引读取失败。

## 插件安装失败

- 确认市场索引条目有正确的 `id`、版本和 `source_dir`。
- 确认仓库 ZIP 内存在对应 `plugin.json`。
- 检查 NOOR 对插件目录是否有写权限。
- 重新安装前可选择保留插件私有数据。

## 媒体库显示等待入库

- 确认下载任务已经完成且文件可见。
- 检查媒体服务器路径映射。
- 触发媒体库扫描并等待服务器刷新。
- 确认作品编号在文件名、NFO 或 Provider ID 中可识别。

## GPU 任务显存不足

- 停止不需要的模型服务或 GPU 任务。
- 降低并发、模型规模或处理分辨率。
- 检查 GPU Guard 策略和最低空闲显存配置。
- 使用 `nvidia-smi` 确认占用者，再决定是否终止进程。

## 提交 Issue 前

请提供版本、操作步骤、预期结果和已脱敏错误信息。删除用户名、真实路径、内网地址、Cookie、Token 与媒体标识。
